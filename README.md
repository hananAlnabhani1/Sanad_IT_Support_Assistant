# Sanad — IT Support Assistant

An educational project demonstrating how LLM application concepts can support ERP technical support workflows.

## Project Goal
Assist support staff with organizing tickets, checking ticket status, booking support appointments, and escalating requests.

## Key Concepts
- Conversation state and context management.
- Provider adapters, retry, and fallback.
- Structured ticket extraction and Pydantic validation.
- Tool workflows and authorization checks.
- Guardrails and personal data masking.
- Evaluation and regression checks.
- Model routing, caching, and cost estimation.

## Technologies
- Python
- Pydantic
- Google Colab

## How to Run
1. Open `Sanad_IT_Support_Assistant.ipynb` in Google Colab.
2. Run the cells in order from top to bottom.
3. Review the examples and test results for each lab.

## Project Scope
This project uses educational simulations. It does not connect to a live AI model or ERP system. Model responses, tool actions, latency, and costs are simulated.
